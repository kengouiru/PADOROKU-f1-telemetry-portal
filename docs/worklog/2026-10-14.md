# Worklog: 2026-10-14

## 1. ユーザー依頼（原文要旨）
- アプリ全体が不具合:
  - `localhost:3000` でどのボタンを押しても変化がない。
  - 前回大会確認セクションが見当たらず、直近のレースであるシンガポールGPの結果も反映されていない。
  - ブランチの `https://padoroku-f1-telemetry-portal-git-preview-update-kengo4.vercel.app/` と本番の `https://padoroku-f1-telemetry-portal.vercel.app/` ですべて反映させたはずなのに状況が異なる。見直してほしい。

## 2. 調査結果・発見
1. **`localhost:3000` でボタンが無反応だった原因**:
   - `components/hubs/SeasonHub.tsx` の1行目にあるべき `'use client';` ディレクティブより上に `import { PostRaceReviewModal } from '@/components/pitwall/PostRaceReviewModal';` が誤って挿入されており、Next.js App Router のクライアントコンポーネント境界とハイドレーションが破損していた。
   - `app/page.tsx` において、デスクトップ用コンテナ（`hidden lg:flex`）とモバイル用コンテナ（`lg:hidden flex`）の2箇所で `{mainHubContent}` が同時にマウントされており、すべてのハブコンポーネントが2重に初期化され、OpenF1 API / Jolpica API リクエストが倍増して `HTTP 429 Too Many Requests` を引き起こしていた。
   - `components/telemetry/DetailedTelemetryChart.tsx` および `components/telemetry/TelemetryDeltaAnalyzer.tsx` において、早期リターン（`if (isLoading || !telemetryData) return ...`）の後に複数の `useMemo` フックが呼ばれており、データ取得完了時の再レンダリングで React の Hook 数不一致エラー（Runtime Error）および Vercel ビルド時の ESLint `react-hooks/rules-of-hooks` エラーを引き起こしていた。
2. **前回大会確認セクション（Previous Race Summary）とシンガポールGP結果が未表示だった原因**:
   - `components/hubs/SeasonHub.tsx` 内の `PreviousRaceHero` 呼び出し箇所の直前に閉じられていない `{/*` コメントがあり、セクションごとコメントアウトされていた。また `previousRace` の `useMemo` が `return null;` に書き換えられていた。
   - `lib/sessionResultsService.ts` の `COMPLETED_2026_RACES` が第14戦（オランダGP）までしか登録されておらず、第15戦（アゼルバイジャンGP）、第16戦（マレーシアGP）、第17戦（シンガポールGP）の公式リザルトと、`data/f1SeasonData.ts` の第17戦終了時点のポイントランキングが未反映だった。
   - `lib/openf1LiveResult.ts` と `components/pitwall/PostRaceReviewModal.tsx` に `const year = 2024;` のハードコードフォールバックが残存していた。
3. **Vercel の本番URL（`main`）とプレビューURL（`preview-update`）の乖離・ビルド失敗の原因**:
   - リポジトリルートに調査用スクリプト・一時ファイル（`scratch/`, `fix_*.js`, `test*.js`, `dom.html` 等）がコミットされた状態で `preview-update` ブランチ（`478c6f6`）がプッシュされ、上記の ESLint `react-hooks/rules-of-hooks` エラーによって Vercel ビルドが Exit Code 1 で失敗していた。また、`main` と `preview-update` の指すコミットが乖離していた。
